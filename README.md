запуск
1. Клонировать репозиторий: `git clone — скачивает копию репозитория с GitHub на компьютер
2. Перейти в папку: cd lab2_todo — переходим внутрь папки. cd lab2_todo - имя созданного репозитория
3. Установить зависимости: dart pub get - Эта команда скачивает все пакеты, которые нужны проекту
4. Запустить: dart run - запустится файл, void main() — стандартная точка входа любой Dart-программы

изучили
1. Классы и объекты в Dart — создание класса Todo, работа с полями и методами
2. Конструкторы — краткая запись конструктора с this.id, this.title и инициализацией isDone
3. Геттеры — вычисляемое свойство status, которое возвращает «выполнено» или «в процессе»
4. Статические поля — счётчик _counter для автоматической генерации ID задач
5. Пакеты и pub.dev — подключение пакета ansicolor для цветного вывода в консоль

ответы на вопросы
1. Поле принадлежит объекту и живёт с ним. Переменная в функции — только во время её выполнения
2. Специальный метод, вызываемый при создании объекта. Инициализирует поля начальными значениями
3. Проверяет, что метод существует в родителе, и защищает от опечаток. Без него код работает, но ошибку в имени компилятор не заметит
4. Обычное поле — у каждого объекта своё. Статическое — одно на весь класс
5. Приватность на уровне файла. Переменная доступна только внутри `todo.dart`, из других файлов — нет
